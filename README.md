电容器制造商静态展示页面 | Capacitor Manufacturer Static Site

## 部署说明

本项目使用 GitHub Pages 托管。

1. 将仓库推送至 GitHub
2. 在仓库 **Settings → Pages → Source** 设为 `main` 分支
3. 等待部署后访问 `https://[your-username].github.io/beryl-capacitor`

## 技术栈

- 纯 HTML5 + CSS3 + Vanilla JS（零依赖）
- Google Fonts: Noto Sans SC
- 响应式设计，支持移动端
